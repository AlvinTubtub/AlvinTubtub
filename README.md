## 🚀 Featured Projects

### 📈 PSE Pulse — Stock Price Forecasting Platform

A full-stack educational stock market forecasting platform developed for **15 Philippine Stock Exchange (PSE) companies across five sectors**.

The platform compares multiple statistical and machine learning models to generate next-trading-session stock price forecasts.

**Key Features**
- Historical OHLCV market data processing and validation
- Lag-Informed Regression, ARIMA, and LSTM forecasting models
- Naive benchmark evaluation
- Model comparison using RMSE, MAE, MASE, and R²
- Interactive stock charts, backtesting, and residual analysis
- Automated market data ingestion and forecasting workflows
- Responsive dashboard with company profiles and watchlists

**Technologies:** Python, Pandas, NumPy, Scikit-learn, Statsmodels, PyTorch, Next.js, TypeScript, GitHub Actions, Vercel

🌐 **Live Website:** https://pse-pulse.vercel.app/

🔗 **Repository:** https://github.com/AlvinTubtub/Capstone2-A4103-DigitalDelvers-SY26-27

### 📊 ForecastPH — Automated Stock Forecasting Dashboard

A Python-based Streamlit dashboard for cross-sector next-day stock price forecasting of selected Philippine Stock Exchange companies.

The system integrates an automated data processing pipeline with machine learning and statistical forecasting methods.

**Key Features**
- Automated extraction and validation of PSE market data
- Historical stock price and OHLCV visualization
- Lag-Informed Regression, ARIMA, and LSTM models
- Model evaluation and best-model selection
- Actual-versus-predicted backtesting charts
- Automated pipeline execution using GitHub Actions
- Interactive Streamlit dashboard with Plotly charts

**Technologies:** Python, Streamlit, Plotly, Pandas, NumPy, Scikit-learn, Statsmodels, pmdarima, PyTorch, GitHub Actions

🔗 **Repository:** https://github.com/AlvinTubtub/streamlit-pse-stock-price-forecast-dashboard-automation
